数学建模常用符号解释

本文档是数学建模（研究生数学建模竞赛/国赛/美赛）中常用数学符号的速查手册，与 01~06 号文档（回归分析系列）配套使用。每个算法文档第五节也包含该算法专属的「符号说明」表，本文档给出全局通用约定。

论文写作建议：符号首次出现时必须说明含义；建议在论文开头（或模型建立章节前）列一张符号表，全文统一，评委友好。

十一、论文写作中的符号使用规范​

  1. 统一性：同一符号全文只代表一个量；不同量用不同符号。
  2. 首次出现必说明：如"设 yyy 为预测销量（万辆），x1x_1x1​ 为广告投入（万元）……"。

十二、快速记忆口诀​

  • 帽子  ^\hat{\ } ^ 是估计，横线  ˉ\bar{\ } ˉ 是均值，真值不带帽；
  • 希腊字母：β\betaβ 回归系数、ε\varepsilonε 误差、μ/σ\mu/\sigmaμ/σ 均值方差、λ\lambdaλ 正则、η\etaη 学习率、θ\thetaθ 参数；
  • 大小写分工：Σ\SigmaΣ 求和、σ\sigmaσ 标准差；Π\PiΠ 求积、π\piπ 圆周率；
  • 指标方向：R²、AUC、F1 越大越好；MSE、RMSE、MAE、AIC、BIC、VIF、p 值越小越好。
