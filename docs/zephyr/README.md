# Zephyr 通用开发教程：ESP32-S3 与 STM32F407

> 面向本工作区的 Zephyr **4.2.0**，以 ESP32-S3 DevKitC 和 FK407M2（STM32F407ZG）为例。目标是学会“通用业务代码 + 板级设备树适配”，不是把厂商 HAL 调用分别塞进两套 `main.c`。

## 阅读约定

- 工作区：`F:/zephyr_tutorial/zephyr_workspace`。
- ESP32 目标：`esp32s3_devkitc/esp32s3/procpu`。
- STM32 目标：`fk407m2/stm32f407xx`，不是 `black_f407zg_pro`。
- 全部终端命令默认从工作区执行，使用原生 west，不依赖自制构建脚本。
- 每章实验单独建应用、单独建输出目录。不同章节的引脚方案**不能直接叠加成一个工程**。
- 标为“完整 main.c”的代码可作为该章应用入口；标为“片段”的代码必须放入已有初始化流程，不能独立当完整工程。
- 示例中的外接引脚是教学方案，不表示你的实物已接好。连接前核实模组型号、板上引出、复用和电气限制。

## 验证边界

**已实测的基线**：本工作区 `apps/shared_demo` 在两板均完成全新和增量编译，使用同一份业务源码；未烧录验证硬件。

**本教程其余实验**：依据本地 Zephyr 4.2 源码、API、板定义与官方 sample 编写；除特别标明外，属于待编译/上板验证的教学示例，不宣称每个实验已经测试通过。无线功能可能需要额外模块，USB 需要额外板级配置。教程编写不会自动下载模块、改系统设置或烧录设备。

## 两块芯片的能力边界

| 能力 | ESP32-S3 | STM32F407ZG / FK407M2 |
|---|---|---|
| CPU | Xtensa；本教程使用 procpu 板目标 | ARM Cortex-M4F |
| 通用 GPIO / UART / I2C / SPI / PWM / ADC | 有，需启用对应驱动和引脚 | 有，需启用对应驱动和引脚 |
| Wi-Fi | 内置 2.4 GHz Wi-Fi | **无内置无线射频**，需要外接模块/网卡 |
| BLE | 内置 BLE；不是经典蓝牙 SPP | **无内置 BLE 控制器**，可外接 HCI 控制器或完整蓝牙模块 |
| USB | USB OTG 与 USB Serial/JTAG 是不同功能，须区分接口 | 芯片有 USB OTG 控制器；能否使用取决于板接线、PHY 和配置 |
| 控制台基线 | UART0，GPIO43/44 | USART1，PA9/PA10 |
| LED 基线 | GPIO4 外接普通 LED | PC13 板载低有效 LED |

STM32 没有 Wi-Fi/BLE，**不能通过打开两个 Kconfig 选项凭空获得无线功能**。通用的是网络/蓝牙上层接口及业务逻辑，底层设备和可用功能仍由硬件决定。

## 推荐学习顺序

先跑通串口和 LED → 学会设备树 → 线程与消息队列 → I2C 传感器 → ADC/PWM/SPI → 分别学习 Wi-Fi、BLE、USB → 最后组合成综合项目。

建议每次只引入一个变量：先编译，再接线，再观察日志，再加入并发。不要同时改变板型、引脚、电源、通信协议和线程结构。

## 本地资料优先

官方在线 `latest` 文档可能属于新版本。本教程以工作区中的 `zephyr/doc/`、`zephyr/samples/`、`zephyr/include/zephyr/`、板文件为准。遇到符号不存在、示例路径变化时先核对版本，不盲目复制别的版本配置。
