# 数学建模常用符号解释

> 本文档是数学建模（研究生数学建模竞赛/国赛/美赛）中常用数学符号的速查手册，与 `01`~`06` 号文档（回归分析系列）配套使用。每个算法文档第五节也包含该算法专属的「符号说明」表，本文档给出**全局通用约定**。
>
> 论文写作建议：符号首次出现时必须说明含义；建议在论文开头（或模型建立章节前）列一张符号表，全文统一，评委友好。

## 一、希腊字母（建模高频）

| 符号 | 大写 | 读音 | 常见含义与示例 |
|------|------|------|----------------|
| $\alpha$ | A | alpha | 显著性水平（$\alpha=0.05$）、学习率、截距参数 |
| $\beta$ | B | beta | 回归系数（$\beta_0, \beta_1$）、第二类错误概率 |
| $\gamma$ | $\Gamma$ | gamma | 折扣因子、Gamma 分布、参数 |
| $\delta$ | $\Delta$ | delta | 微小增量、示性参数；$\Delta$ 表示变化量（$\Delta x = x_2 - x_1$） |
| $\varepsilon$ | E | epsilon | **随机误差项**（$\varepsilon \sim N(0,\sigma^2)$）、很小的正数 |
| $\eta$ | H | eta | 学习率（梯度下降步长 $\eta=0.01$） |
| $\theta$ | $\Theta$ | theta | 模型参数向量（非线性回归 $f(x;\theta)$） |
| $\lambda$ | $\Lambda$ | lambda | 正则化系数（岭回归 $\lambda$）、特征值、泊松分布参数 |
| $\mu$ | M | mu | 总体均值（$\mu=0$）、期望 |
| $\nu$ | N | nu | 自由度 |
| $\xi$ | $\Xi$ | xi | 随机变量、干扰项 |
| $\pi$ | $\Pi$ | pi | 圆周率；$\Pi$ 为求积符号 |
| $\rho$ | P | rho | 总体相关系数（样本相关系数为 $r$） |
| $\sigma$ | $\Sigma$ | sigma | 标准差（$\sigma^2$ 为方差）、sigmoid 函数 $\sigma(z)$；$\Sigma$ 为求和符号 |
| $\tau$ | T | tau | 阈值、时滞、时间点 |
| $\phi$ | $\Phi$ | phi | 概率密度函数、相位角 |
| $\chi$ | X | chi | 卡方分布 $\chi^2$（拟合优度检验） |
| $\omega$ | $\Omega$ | omega | 角频率；$\Omega$ 常表示样本空间/全集 |
| $\nabla$ | — | nabla | 梯度算子（$\nabla L$ 表示损失函数的梯度） |

## 二、常用数学符号

| 符号 | 名称 | 含义 | 示例 |
|------|------|------|------|
| $\sum$ | 求和 | 累加 | $\sum_{i=1}^{n} x_i = x_1 + \cdots + x_n$ |
| $\prod$ | 求积 | 累乘 | $\prod_{i=1}^{n} x_i$ |
| $\in$ / $\notin$ | 属于 / 不属于 | 集合关系 | $x \in \mathbb{R}$ |
| $\forall$ / $\exists$ | 任意 / 存在 | 逻辑量词 | $\forall \varepsilon > 0$ |
| $\partial$ | 偏导 | 多元函数求导 | $\dfrac{\partial L}{\partial \beta}$ |
| $\nabla$ | 梯度 | 多变量一阶导数向量 | $\nabla L(\theta)$ |
| $\int$ | 积分 | 连续求和 | $\int_0^T f(t)\,dt$ |
| $\lim$ | 极限 | 趋近 | $\lim_{x \to \infty} e^{-x} = 0$ |
| $\min$ / $\max$ | 最小 / 最大 | 目标函数 | $\min_{\beta} \sum (y_i - \hat{y}_i)^2$ |
| $\arg\min$ / $\arg\max$ | 取最小/最大的自变量 | 求最优解点 | $\hat{\beta} = \arg\min_{\beta} L(\beta)$ |
| $=$ / $\approx$ / $\neq$ | 等于 / 约等于 / 不等于 | — | $\pi \approx 3.14$ |
| $\le$ / $\ge$ | 小于等于 / 大于等于 | 约束条件 | $\text{s.t. } x \ge 0$ |
| $\propto$ | 正比于 | 成比例 | $P \propto e^{-\lambda t}$ |
| $\to$ / $\Rightarrow$ | 趋近 / 推出 | 极限与逻辑 | $x \to 0 \Rightarrow \sin x \approx x$ |
| $\infty$ | 无穷 | 极限、区间 | $[0, +\infty)$ |
| $\lvert x \rvert$ | 绝对值 | 距离、误差大小 | $\lvert e_i \rvert$ |
| $\lVert x \rVert$ | 范数 | 向量长度（$\lVert \cdot \rVert_1$ 一范数，$\lVert \cdot \rVert_2$ 二范数） | $\lVert \beta \rVert_2^2 = \sum \beta_j^2$ |
| $n!$ | 阶乘 | 排列组合 | $n! = n(n-1)\cdots 1$ |
| $C_n^k$ / $\binom{n}{k}$ | 组合数 | 从 n 中取 k | $\binom{n}{k} = \frac{n!}{k!(n-k)!}$ |
| $\cdot$ | 点乘 | 向量内积 | $x \cdot y$ |

## 三、上下标与"帽子"记号（最重要约定）

| 记号 | 名称 | 含义 | 示例 |
|------|------|------|------|
| $\bar{x}$ | 上横线（bar） | 样本均值 | $\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$ |
| $\hat{y}$ | 帽子（hat） | 预测值/估计值 | $\hat{y}_i = \hat{\beta}_0 + \hat{\beta}_1 x_i$ |
| $\hat{\beta}$ | 帽子（hat） | 参数估计值（未知真值 $\beta$ 的估计） | $\hat{\beta} = (X^\top X)^{-1} X^\top y$ |
| $\tilde{x}$ | 波浪线（tilde） | 中位数/变换后的量 | $\tilde{x}$ 为中位数 |
| $x^{*}$ | 星号 | 最优解、标准化后的量 | $\beta^{*}$ 为标准化系数 |
| $x^{(k)}$ | 圆括号上标 | 第 k 次迭代值 | $\theta^{(k+1)} = \theta^{(k)} - \eta \nabla L$ |
| $x_i$ | 下标 i | 第 i 个样本 | $x_i$ 为第 i 个观测 |
| $x_{ij}$ | 双下标 | 第 i 个样本的第 j 个特征 | $X = (x_{ij})_{n \times p}$ |
| $X^{\top}$ | 上标 T | 矩阵转置 | $X^{\top}X$ 为信息矩阵 |
| $X^{-1}$ | 上标 -1 | 矩阵求逆 | $(X^{\top}X)^{-1}$ |
| $\beta_0$ | 下标 0 | 截距项（常数项） | $y = \beta_0 + \beta_1 x$ |
| $y_{(i)}$ | 次序统计量 | 排序后第 i 个 | QQ 图中的分位数 |

> **核心区分**：真值（$\beta, y$）vs 估计值（$\hat{\beta}, \hat{y}$）vs 均值（$\bar{y}$）vs 观测值（$y_i$）。论文中混用是大忌。

## 四、统计符号

| 符号 | 名称 | 含义 | 公式 |
|------|------|------|------|
| $\mu$ | 总体均值 | 全体数据的平均 | $\mu = E[X]$ |
| $\bar{x}$ | 样本均值 | 抽样数据的平均 | $\bar{x} = \frac{1}{n}\sum x_i$ |
| $\sigma^2$ / $s^2$ | 总体/样本方差 | 数据离散程度 | $s^2 = \frac{1}{n-1}\sum (x_i - \bar{x})^2$ |
| $\sigma$ / $s$ | 总体/样本标准差 | 方差开方，与数据同量纲 | — |
| $E[X]$ | 期望 | 随机变量的均值 | $E[X] = \sum x P(x)$ |
| $\text{Var}(X)$ | 方差 | $E[(X-E[X])^2]$ | — |
| $\text{Cov}(X,Y)$ | 协方差 | 两变量共同变动程度 | $\text{Cov}(X,Y) = E[(X-\mu_X)(Y-\mu_Y)]$ |
| $N(\mu, \sigma^2)$ | 正态分布 | 均值 $\mu$、方差 $\sigma^2$ | $\varepsilon \sim N(0, \sigma^2)$ |
| $U(a,b)$ | 均匀分布 | [a,b] 上等概率 | — |
| $P(A)$ | 概率 | 事件 A 发生概率 | $P(y=1 \mid x)$ |
| $p$ 值 | p-value | 拒绝原假设的最小显著性水平 | $p < 0.05$ 显著 |
| $\alpha$ | 显著性水平 | 检验阈值，通常 0.05 / 0.01 | — |
| $1-\alpha$ | 置信水平 | 置信区间的把握 | 95% 置信区间 |
| $r$ / $\rho$ | 样本/总体相关系数 | 线性相关强度（-1~1） | Pearson 相关系数 |
| $R^2$ | 决定系数 | 拟合优度（0~1） | 见 01 号文档 |
| $\text{df}$ | 自由度 | 独立信息量 | 一元回归残差 df = n−2 |
| SE | 标准误 | 估计量标准差 | $SE(\hat{\beta}_1)$ |
| CI | 置信区间 | 参数真值的区间估计 | $\hat{\beta}_1 \pm t_{\alpha/2} \cdot SE$ |
| $H_0$ / $H_1$ | 原/备择假设 | 假设检验的两方 | $H_0: \beta_1 = 0$ |

## 五、线性代数记号（回归/优化建模必用）

| 记号 | 含义 | 说明 |
|------|------|------|
| $x$（小写粗体或带箭头） | 列向量 | $x = (x_1, x_2, \dots, x_p)^\top$ |
| $X$（大写） | 设计矩阵 | $n$ 行（样本）× $p$ 列（特征） |
| $X \in \mathbb{R}^{n \times p}$ | 矩阵维数 | n 个样本、p 个特征 |
| $y$ | 响应向量 | $y = (y_1, \dots, y_n)^\top$ |
| $\beta$ | 系数向量 | $\beta = (\beta_0, \beta_1, \dots)^\top$ |
| $\varepsilon$ | 误差向量 | $y = X\beta + \varepsilon$ |
| $I$ | 单位矩阵 | 对角线为 1 |
| $X^\top X$ | 信息矩阵 | 正规方程核心 |
| $\lVert \beta \rVert_1$ | L1 范数 | $\sum \lvert \beta_j \rvert$，Lasso 惩罚 |
| $\lVert \beta \rVert_2^2$ | L2 范数平方 | $\sum \beta_j^2$，岭回归惩罚 |

## 六、机器学习/建模通用符号

| 符号 | 含义 | 约定 |
|------|------|------|
| $x$ | 自变量/特征/解释变量 | 输入 |
| $y$ | 因变量/响应变量/标签 | 输出（回归为连续值，分类为 0/1 等） |
| $\hat{y}$ | 模型预测值 | $\hat{y} = f(x; \theta)$ |
| $e_i$ 或 $\varepsilon_i$ | 残差/误差 | $e_i = y_i - \hat{y}_i$（残差用观测数据可算，误差是理论量） |
| $f(\cdot)$ | 模型函数 | 映射关系 |
| $\theta$ / $w$ / $\beta$ | 模型参数 | 待估参数向量 |
| $L(\theta)$ | 损失函数 | 越小越好；如 $L = \sum (y_i - \hat{y}_i)^2$ |
| $\lambda$ | 正则化系数 | 惩罚强度，越大收缩越强 |
| $\eta$ | 学习率 | 梯度下降步长 |
| $n$ | 样本量 | 数据行数 |
| $p$ | 特征数 | 自变量个数 |
| $k$ | 折数/类别数 | k 折交叉验证、k 个类别 |
| $t$ | 时间变量 | 时序问题 |
| $T$ | 周期/终止时刻 | 预测期长度 |
| $\min / \max$ | 目标函数方向 | 如 $\min \sum e_i^2$ |
| $\text{s.t.}$ | 约束条件（subject to） | 线性规划：$\max z = c^\top x \ \text{s.t. } Ax \le b, x \ge 0$ |

## 八、常用评估指标缩写速查

| 缩写 | 全称 | 含义 | 取值范围 | 方向 |
|------|------|------|----------|------|
| MSE | Mean Squared Error | 均方误差 | $[0, +\infty)$ | 越小越好 |
| RMSE | Root Mean Squared Error | 均方根误差（与 y 同量纲） | $[0, +\infty)$ | 越小越好 |
| MAE | Mean Absolute Error | 平均绝对误差（对离群点不敏感） | $[0, +\infty)$ | 越小越好 |
| MAPE | Mean Absolute Percentage Error | 平均绝对百分比误差 | $[0, +\infty)$ | 越小越好 |
| SSE | Sum of Squared Errors | 残差平方和 | $[0, +\infty)$ | 越小越好 |
| $R^2$ | R-squared | 决定系数 | $(-\infty, 1]$ | 越接近 1 越好 |
| Adj-$R^2$ | Adjusted R-squared | 调整决定系数（惩罚变量数） | 同 $R^2$ | 越接近 1 越好 |
| AIC / BIC | 赤池/贝叶斯信息准则 | 模型选择（惩罚复杂度） | 越小越好 | 越小越好 |
| VIF | Variance Inflation Factor | 方差膨胀因子（>10 共线性严重） | $[1, +\infty)$ | 越接近 1 越好 |
| TP/FP/TN/FN | 混淆矩阵四格 | 分类预测正误统计 | 计数 | — |
| Acc | Accuracy | 准确率（不平衡数据会失真） | $[0,1]$ | 越大越好 |
| P / R | Precision / Recall | 精确率 / 召回率 | $[0,1]$ | 越大越好 |
| F1 | F1-score | P 与 R 的调和平均 | $[0,1]$ | 越大越好 |
| AUC | Area Under ROC Curve | ROC 曲线下面积 | $[0.5,1]$ | 越大越好 |
| CV | Cross Validation | 交叉验证（如 5 折 CV） | — | 泛化评估手段 |
| GCV | Generalized CV | 广义交叉验证（岭回归选 λ） | 越小越好 | 越小越好 |

## 十一、论文写作中的符号使用规范

1. **统一性**：同一符号全文只代表一个量；不同量用不同符号。
2. **首次出现必说明**：如"设 $y$ 为预测销量（万辆），$x_1$ 为广告投入（万元）……"。
3. **区分真值与估计值**：参数真值 $\beta$、估计值 $\hat{\beta}$、均值 $\bar{\beta}$ 不可混用。
4. **下标约定清晰**：$i$ 表示第 $i$ 个样本，$j$ 表示第 $j$ 个特征，全文一致。
5. **建议在论文开篇列符号表**（模板如下）：

> **符号说明**
> | 符号 | 含义 | 单位 |
> |------|------|------|
> | $n$ | 样本数量 | 个 |
> | $p$ | 特征（自变量）个数 | 个 |
> | $y_i$ | 第 $i$ 个样本的响应变量 | — |
> | $x_{ij}$ | 第 $i$ 个样本第 $j$ 个特征 | — |
> | $\beta_j$ | 第 $j$ 个回归系数 | — |
> | $\hat{\beta}_j$ | $\beta_j$ 的估计值 | — |
> | $\varepsilon_i$ | 随机误差项，$\varepsilon_i \sim N(0, \sigma^2)$ | — |
> | $R^2$ | 决定系数 | 无量纲 |
> | RMSE | 均方根误差 | 与 $y$ 同量纲 |
> | $\lambda$ | 正则化系数 | 无量纲 |
> | $\alpha$ | 显著性水平 | 无量纲 |

## 十二、快速记忆口诀

- **帽子 $\hat{\ }$ 是估计，横线 $\bar{\ }$ 是均值，真值不带帽**；
- **希腊字母**：$\beta$ 回归系数、$\varepsilon$ 误差、$\mu/\sigma$ 均值方差、$\lambda$ 正则、$\eta$ 学习率、$\theta$ 参数；
- **大小写分工**：$\Sigma$ 求和、$\sigma$ 标准差；$\Pi$ 求积、$\pi$ 圆周率；
- **指标方向**：R²、AUC、F1 越大越好；MSE、RMSE、MAE、AIC、BIC、VIF、p 值越小越好。
